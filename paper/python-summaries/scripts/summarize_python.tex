Python Documentation Summarizer.

Extracts module-level documentation from all project Python files using
pdoc3, converts the resulting Markdown-Extra output to LaTeX fragments,
and writes them into \texttt{paper/python-summaries/} as individual .tex
files. Generates two index files:

\begin{itemize}
    \tightlist
  \item
    \texttt{paper/python-summaries/index.tex} --- one
    \texttt{\textbackslash{}section} per module with its docstring
    rendered as LaTeX.
  \item
    \texttt{paper/python-summaries/index-code.tex} --- one
    \texttt{\textbackslash{}section} per module with the raw source
    inlined via \texttt{\textbackslash{}inputmintedstyledtwocolumns}.
\end{itemize}

Module discovery covers: - main.py in the project root - Everything
under \texttt{src/} and \texttt{scripts/} - Excludes
\texttt{src/migrations/}, \_\_init\_\_.py files that are empty, and
\texttt{.history/} artefacts.
